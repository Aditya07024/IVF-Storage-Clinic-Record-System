Explicit Included Scope of Work (Deliverables List)

The agreed fixed budget of ₹50,000 strictly covers the implementation of the following enumerated features only:

01. Cryo Storage Visualizer
  • Interactive 3D-styled physical hierarchy (8 Cans, 80 Canisters, 160 Levels, 160 Goblets, 1,760 VisoTubes, 17,600 Straws).
  • Radial Pizza-Slice Goblet Wheel & 8-step occupancy intensity heatmap view.
  • Viso Tube Specimen Inspector modal with pinned header/footer and scrollable middle body.
02. Patient Medical Directory
  • Complete patient profiles, demographic records & clinical notes management.
  • Mobile-tailored side-by-side Visit Date & Freezing Date input layout.
  • Instant search engine & multi-field filters (ID, Name, Phone, Freezing Date, Visit Date).
  • Mobile responsive popups with background body scroll lock.
03. AI / Google Cloud Vision OCR
  • Upload handwritten/printed physical clinic records (JPEG, PNG, HEIC, PDF).
  • Automatic data extraction & side-by-side verification review editor.
  • Instant patient record creation from verified OCR scans.
04. Cryo Thaw Workflow Engine
  • Direct straw thaw execution from Viso Tube modal or Thaw Workflow tab.
  • Real-time background task queue with status toast notifications.
  • Audit logging for every thaw operation and storage movement.
05. Enterprise Security & Auth
  • Role-Based Access Control (RBAC) with Admin and Staff roles.
  • Argon2id password hashing, JWT tokens & Access Key security shield.
  • Helmet HTTP headers, CORS policies, Express rate limiting & trust proxy support.
06. Database & Cloud Deployment
  • Serverless Neon PostgreSQL cloud database integration with Prisma ORM.
  • Optimized bulk seeding script for instant storage initialization.
  • Deployment setup on cloud server (Render/Vercel/Cloud host).
